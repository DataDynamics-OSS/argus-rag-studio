* 아키텍처 개요 — 구성 요소·데이터 흐름을 사용자 관점으로 정리

* 코드 구조 안내 — backend/app 모듈 지도, frontend features 구조
* 확장 포인트 — 라우터(라우팅 정책)·인제스천 transform·파서 추가 방법
* REST API 연동 — 인증(API 키)·주요 엔드포인트·에러 규약
* 빌드·패키징·배포 — 이미지 빌드, tar/rpm 패키징, 버전 정책(VERSIONING.md)
* 기여 가이드 — 브랜치·커밋 규약, 테스트, 문서화 규칙
