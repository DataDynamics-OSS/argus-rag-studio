= 피드백 루프

답변에 대한 사용자 평가(👍/👎)를 모아 평가 골든셋으로 승격해 품질을 지속 보강하는 루프입니다.

== 수집

Playground·Chat 답변 하단의 👍/👎 위젯으로 수집합니다.

* 👍 — 즉시 전송.
* 👎 — 코멘트·수정답변을 입력받아 전송.

각 피드백은 `trace_id` 로 특정 답변에 귀속됩니다(질문·답변·컬렉션·코멘트·수정답변·기대출처 저장).

== 승격(promote)

`/dashboard/feedback` 관리 화면에서 피드백을 평가 데이터셋 항목으로 승격합니다.

* 질문 → 골든셋 question
* 수정답변(또는 원답변) → expected_answer
* 기대출처 → expected_sources

승격 시 상태가 `promoted` 로 바뀌고 `promoted_item_id` 로 골든셋 항목을 추적합니다.
무시(dismiss)·삭제도 가능합니다.

== 상태·통계

상태(new / promoted / dismissed)·평가(up/down) 필터와 통계 카드를 제공합니다.
