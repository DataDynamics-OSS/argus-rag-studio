= 평가 (골든셋·Run·지표)

평가 하니스로 RAG 품질을 정량 측정합니다. 골든 데이터셋에 대해 파이프라인을 실행하고 검색·생성 지표를 산출합니다.

== 골든 데이터셋

(질문, 기대답변, 기대출처) 항목의 집합. 수동 입력 또는 피드백 승격(xref:eval/feedback.adoc[피드백 루프])으로 구성합니다.

== 평가 Run

비동기 워커가 항목별로 RAG 파이프라인을 실행합니다.

[cols="1,3"]
|===
| 검색 지표 | *Hit Rate*, *MRR* — 기대 출처 매칭(LLM 불필요)
| 생성 지표 | *LLM-as-judge* — faithfulness · answer_relevance · correctness (`judge` 옵션)
|===

Run 은 대상 컬렉션의 거리 메트릭과 함께 기록되며, 실행별 지표 스냅샷을 비교할 수 있습니다.

== 사용

. *평가* 화면에서 데이터셋 생성 → 항목 추가.
. *Run 실행* — 모드·리랭크·judge·top_k 지정.
. 지표 테이블과 항목별 결과 확인.
