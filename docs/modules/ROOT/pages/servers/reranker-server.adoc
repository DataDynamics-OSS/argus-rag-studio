= 리랭커 서버

FastEmbed cross-encoder 기반 *TEI 호환* 재정렬 서버(`extensions/reranker_server/`)입니다. RAG 백엔드와 독립
배포물로, 컬렉션/파이프라인 리랭커를 `cross_encoder` 로 두고 이 서버를 가리키면 됩니다.

== 엔드포인트

[cols="1,3"]
|===
| `POST /rerank` | `{query, texts[, model, top_n]}` → `[{index, score}, ...]` (점수 내림차순)
| `GET /v1/models` | 제공 cross-encoder 모델 목록
| `GET /health` | 헬스체크(무인증)
|===

== 실행

[source,bash]
----
cd extensions/reranker_server
docker compose up -d --build     # 포트 8081
# 또는: make run
----

== 주요 설정(환경변수)

[cols="1,1,3"]
|===
| `RERANK_API_KEY` | `changeme` | Bearer 인증. RAG `rerank.api_key` 와 동일해야 함. 빈값이면 무인증.
| `RERANK_DEFAULT_MODEL` | ms-marco-MiniLM-L-6-v2 | model 미지정 시 사용. 다국어는 jina-reranker-v2-base-multilingual 권장
| `RERANK_PRELOAD` | `false` | 시작 시 기본 모델 미리 로딩
|===

== 연결

RAG 백엔드 설정:

[source,properties]
----
rerank.provider=cross_encoder
rerank.server_url=http://<host>:8081/rerank
rerank.api_key=changeme
----

또는 컬렉션/파이프라인 리랭커를 `cross_encoder` 로 설정. 임베딩 서버와 *별도* 서비스입니다
(임베딩=핫패스 고빈도, 리랭킹=질의당 top-N — 분리해 독립 스케일).
