= 소스 워치(주기 스캔)

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

소스 폴더를 *주기적으로 스캔해 새 문서를 자동 반입* 합니다. 드롭존에 파일을 떨어뜨리기만
하면 되는 무인 운영 단계입니다. 화면: *스토리지 소스* 의 워치 설정.

== 워치 만들기

다룰 내용:

* 소스·폴더(prefix)·주기 설정, 활성/비활성 토글.
* 증분 스캔 원리(한 번 본 파일은 건너뜀 — 지문 캐시)와 파일 교체 시 재반입되는 조건.

== 운영 상태 읽는 법

다룰 내용:

* 마지막 실행 결과(성공/실패, 상태별 집계)와 오류·백오프 표시.
* review 수 표시 — 자동 유입에서 저신뢰 결정이 쌓이는 것을 조기에 인지하는 방법
  (xref:routing/review-queue.adoc[검토 대기] 와 연계).

== 안전장치와 한계

다룰 내용:

* 무한 재시도 방지(같은 파일·같은 정책 버전은 재평가하지 않음 — 정책을 고치면 자동
  재평가).
* 스캔 상한과 대량 폴더 처리 방식(truncated 시 즉시 이어서 실행).
* 워치가 적합하지 않은 경우(실시간성이 필요하면 push 파이프라인 연동 검토).
