= 스토리지 소스 등록

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

라우팅이 문서를 *가져올(pull) 원본 위치* 를 등록합니다. 등록된 소스는 "소스 ID + 경로"로
참조되며, 경로 규칙(path_rule)·폴더 일괄 인테이크·소스 워치가 모두 이 소스를 기준으로
동작합니다. 화면: *스토리지 소스*.

== 소스 종류와 등록

다룰 내용:

* 지원 종류(S3 호환 / NAS 마운트 경로)별 등록 폼과 연결 정보 작성 요령.
* *테스트* 버튼으로 연결 검증(권한·경로 확인) 후 저장하는 절차.
* 읽기 전용 원칙 — RAG Studio 는 소스의 파일을 수정·삭제하지 않는다.

== 소스 이름의 의미

다룰 내용:

* 소스 이름(논리명)이 라우팅 정책의 경로 규칙(storage 필터)에서 참조된다는 것 —
  이름 변경/삭제가 활성 정책에 참조 중이면 거부되는 규칙.
* 이름 짓기 권장(드롭존 용도 중심, 예: `nas-dropzone`, `s3-archive`).

== 경로 구조 설계 (드롭존 규약)

다룰 내용:

* 폴더 구조를 라우팅 규칙으로 쓰는 패턴 — `contracts/`, `hr/` 처럼 대상 지식베이스별
  폴더를 정해 두면 경로 규칙만으로 정확한 배분이 가능.
* 규약을 정할 때 고려사항(부서별 vs 문서유형별, 연도 하위 폴더 등).
