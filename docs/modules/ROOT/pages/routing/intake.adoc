= 인테이크(단건·폴더 일괄)

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

정책이 준비되면 *문서를 실제로 반입* 합니다. 컬렉션을 지정하지 않고 넣으면 정책이 알아서
배분합니다. 화면: 라우팅 > *인테이크* 탭.

== 세 가지 반입 방법

다룰 내용:

* *파일 업로드* — 브라우저에서 직접 올리는 단건 반입.
* *소스에서 가져오기* — 등록된 소스의 경로를 피커로 골라 단건 반입(pull).
* *폴더 일괄 가져오기* — 소스 폴더(prefix) 하위를 한 번에 반입. 파일 수 상한과
  truncated(잘림) 표시의 의미.

== 시뮬레이션 먼저 (dry-run)

다룰 내용:

* 폴더 일괄의 *시뮬레이션* 모드 — 등록 없이 파일별 예상 배분 리포트만 확인.
* 리포트 읽는 법 — 상태별 집계(routed/duplicate/no_route/failed)와 파일별 결과 그리드.
* no_route 가 나오면 정책/폴백을 손보고 다시 시뮬레이션하는 반복 절차.

== 반입 결과 이해

다룰 내용:

* 반입 성공 시 일어나는 일 — 문서 등록 → 인제스천 잡 → 색인(잡 모니터링에서 추적).
* 중복(duplicate) — 같은 내용(content_hash)이 이미 있으면 건너뛰는 멱등 규칙.
* 저신뢰/폴백 배분은 xref:routing/review-queue.adoc[검토 대기] 에 쌓인다는 것.
