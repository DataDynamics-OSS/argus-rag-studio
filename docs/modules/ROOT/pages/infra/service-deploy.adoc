= 서비스 배포

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

등록된 서버(에이전트)에 *추론 서비스를 실제로 올리는* 단계입니다. 임베딩·리랭커·VLM·
검출(OCR)·HWP 렌더 서비스가 대상이며, 배포된 서비스는 이후 모든 화면에서 "서비스 선택"
목록으로 소비됩니다.

== 배포 가능한 서비스 종류

다룰 내용:

* 종류별 역할 한 줄 정리 — embedding(문서/질의 벡터화), reranker(재순위), vlm(이미지
  인식·LLM 분류), detection(레이아웃/OCR), hwp_render(HWP 미리보기).
* 종류별 권장 사양(GPU 필요 여부, 메모리)과 기본 포트.

== 배포 다이얼로그 사용법

다룰 내용:

* 대상 서버 선택 → 서비스 종류 → *모델 선택* (레지스트리 보유 모델 목록에서) 순서.
* 호스트 포트 오버라이드(기본 포트가 점유된 서버), 볼륨/환경변수 오버라이드가 필요한 경우.
* 배포 실행 후 상태 확인(서비스 관리 탭)과 실패 시 로그 확인 경로.

== 배포 후 확인

다룰 내용:

* 서비스 상태 배지·헬스체크로 정상 기동 확인.
* 간단한 호출 테스트(설정 화면의 *테스트* 버튼 활용).

== 운영 작업

다룰 내용:

* 재시작·중지·삭제, 모델 교체(재배포) 절차.
* 버전 업그레이드 시 순서(이미지 → 재배포)와 주의점.
