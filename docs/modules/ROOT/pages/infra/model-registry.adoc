= 모델 레지스트리

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

서비스로 배포할 *모델(임베딩·리랭커·VLM 등)을 등록하고 보유 상태를 관리* 하는 단계입니다.
에어갭(폐쇄망) 환경에서는 외부에서 모델을 팩으로 반입해야 하므로, 배포 전에 반드시 이
단계를 거칩니다. 화면: *파인 튜닝 > 모델*.

== 레지스트리 개념

다룰 내용:

* 레지스트리 항목(종류/이름/HF repo/파라미터)과 "보유(Model Repository 존재)" 상태의 구분.
* 기본 제공(시드) 모델·추천 카탈로그·사용자 등록 모델의 차이.
* 모델이 배포 다이얼로그의 선택 목록으로 이어지는 흐름.

== 모델 등록

다룰 내용:

* 신규 등록 폼(종류·이름·repo·revision·파라미터) 작성 요령 — 임베딩은 차원(dim), VLM 은
  max_len 등 종류별 필수 파라미터.
* 이름 중복 규칙(같은 종류 내 유일).

== 모델 확보 — 두 가지 경로

다룰 내용:

* *온라인 개발망*: "서버에서 팩" 버튼 — HF 다운로드 → 아카이브 → 모델 저장소 업로드
  (동시 1건, 진행 상태 폴링).
* *에어갭*: 외부망에서 `pack_model` 로 팩 생성 → 반입 → 업로드 절차.
* 보유 상태 확인과 미보유 모델 배포 시 거부(409 + 반입 안내) 동작.
