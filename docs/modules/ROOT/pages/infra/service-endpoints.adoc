= 전역 설정과 서비스 연결

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

배포한 서비스를 *어느 기능이 사용할지 연결* 하는 마지막 준비 단계입니다. RAG Studio 의
URL 입력은 대부분 "서비스 선택" 방식입니다 — 배포된 서비스 목록에서 고르면 URL·모델명이
자동으로 채워집니다.

== 서비스 선택 방식 이해

다룰 내용:

* 서비스 픽커의 동작 — 실행 중 서비스 목록에서 선택, URL 손입력 대체.
* *등록된 서비스만 허용* 되는 화면(지식베이스·인제스천·라우팅)과 *직접 입력이 병행
  허용* 되는 화면(전역 설정 — 관리자 전용)의 구분과 이유.
* 서비스 미선택 상태(빈 URL)는 전역 설정으로 폴백된다는 규칙.

== 전역 설정 연결 항목

다룰 내용:

* 설정 화면의 5개 연결 지점 — 임베딩 서버, 생성 LLM, 리랭커, 이미지 분류(VLM), 검출.
* 각 항목의 *테스트* / *차원 감지* 버튼으로 연결 검증하는 절차.
* 새 서비스를 배포하면 전역 설정이 자동 연결되는 경우와 수동 연결이 필요한 경우.

== 지식베이스별 오버라이드

다룰 내용:

* 전역 설정 대신 특정 지식베이스만 다른 서비스를 쓰는 경우(모델 비교 테스트 등) —
  지식베이스 임베딩 URL, 인제스천 이미지 캡션의 VLM 지정, 라우팅 llm_classify 의 서비스 지정.
* 오버라이드 해제(전역 복귀) 방법.
