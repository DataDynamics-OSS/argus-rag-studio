= Argus RAG Studio

*Argus RAG Studio* 는 RAG(Retrieval-Augmented Generation) 파이프라인의 *구축 · 운영 · 평가 · 서빙* 을
한 곳에서 수행하는 플랫폼입니다. 문서를 지식베이스로 인제스천하고, 하이브리드 검색 + 리랭킹 + 생성으로
근거 있는 답변을 만들며, 평가 하니스와 관측으로 품질을 지속 개선합니다.

== 핵심 기능

* *지식베이스* — 문서 업로드 → 파싱 → 청킹 → 임베딩 → pgvector 색인. 컬렉션마다 임베딩 모델·청킹 전략·거리 메트릭·리랭커를 설정.
* *하이브리드 검색* — 벡터(pgvector) + 렉시컬(tsvector)을 RRF 로 융합, 선택적 리랭킹.
* *생성* — 컨텍스트 패킹 + 인용([n]) 그라운딩, 멀티턴 챗(SSE 스트리밍). OpenAI 호환 또는 Claude.
* *파이프라인* — 검색·리랭크·생성 설정을 버전 가능한 1급 자산으로 관리(diff·롤백·비교).
* *평가* — 골든 데이터셋 + Hit Rate/MRR + LLM-as-judge, 답변 피드백을 골든셋으로 승격.
* *운영* — 질의 트레이스(단계별 지연·토큰), p50/p95 통계.
* *문서 라우팅* — 컬렉션 미지정 문서를 정책(경로·파일명·메타데이터·내용·LLM 규칙)으로 자동 배분, 저신뢰 결정은 검토 대기에서 사람이 확인·재배정.
* *모델·서비스 관리* — 모델 레지스트리(에어갭 반입 포함)와 에이전트 기반 원격 서비스 배포(임베딩·리랭커·VLM·검출).
* *파인 튜닝* — 텍스트·이미지 라벨링 → 학습 데이터셋 → 학습 → 모델 등록·배포.
* *추론 서버* — 임베딩·리랭킹을 *로컬(인프로세스)* 또는 *독립 서버* 로 선택.

== 구성 요소

[cols="1,3"]
|===
| Frontend | Next.js 16 대시보드 — 지식베이스·Playground·Chat·파이프라인·평가·운영
| Backend | FastAPI(:4700) — 인제스천·검색·생성·평가·운영·인증
| 데이터 | PostgreSQL + pgvector(청크·벡터·트레이스), MinIO/S3(원본 문서)
| 임베딩 서버 | FastEmbed 기반, OpenAI 호환 `/v1/embeddings` (:8080)
| 리랭커 서버 | FastEmbed cross-encoder, TEI 호환 `/rerank` (:8081)
| 생성 LLM | OpenAI 호환 서버 또는 Claude(anthropic SDK)
|===
