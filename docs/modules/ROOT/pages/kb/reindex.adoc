= 설정 변경·재인덱싱

임베딩·청킹은 벡터 공간을 결정하므로 *생성 후 불변* 이고, 바꾸려면 컬렉션의 모든 문서를 새 설정으로
다시 처리해야 합니다. 상세 화면의 *설정 변경 & 재인덱싱* 다이얼로그가 이를 수행합니다.

== 재인덱싱 다이얼로그

* *임베딩* — 프로바이더/모델/서버 URL 변경(OpenAI 호환은 *테스트* → *모델 불러오기*). 차원은 벡터 컬럼 고정이라 변경 불가.
* *청킹* — 전략/크기/오버랩.
* *거리 메트릭* — 함께 변경 가능(검색 시점 설정이라 엄밀히는 재인덱싱이 필요 없지만 같이 적용).

저장하면 원본(source_uri)이 있는 모든 문서를 `registered` 로 되돌리고 잡을 enqueue 합니다.
모든 잡 완료까지 진행률을 표시합니다.

== 쿼리 시점 설정은 즉시 변경

다음은 저장 벡터와 무관(쿼리 시점)하여 *재인덱싱 없이* 컬렉션 상세 메타데이터에서 즉시 바꿉니다.

* *리랭커* — 프로바이더(none/llm/local/cross_encoder) 및 모델.
* (거리 메트릭은 재인덱싱 다이얼로그에서 변경하지만 실제로는 쿼리 시점 연산자만 바뀜.)

CAUTION: 재인덱싱 중에는 일부 문서의 검색 결과가 일시적으로 달라질 수 있습니다.
