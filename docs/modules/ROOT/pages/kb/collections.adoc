= 지식베이스 생성

지식베이스(컬렉션)는 RAG 검색의 1차 경계입니다. 같은 지식베이스 안의 모든 청크는 동일한 벡터 공간을
공유하므로, *임베딩·청킹 설정은 생성 후 불변* 이며 변경 시 전체 재인덱싱이 필요합니다(리랭커·거리 메트릭은 쿼리 시점이라 즉시 변경 가능).

== 생성 다이얼로그

[cols="1,1,3"]
|===
| 그룹 | 항목 | 설명

| 기본 정보 | 이름 / 설명 | 지식베이스 식별 이름과 메모
.6+| 임베딩 | 프로바이더 | `OpenAI 호환`(외부 서버) / `로컬`(FastEmbed 인프로세스) / `hash`(테스트)
| 모델 | 로컬은 드롭다운, OpenAI 호환은 *모델 불러오기* 로 서버 목록에서 선택
| 차원 | 모델이 결정. 로컬은 자동, OpenAI 호환은 *차원 감지* 버튼
| 서버 URL | OpenAI 호환에서만. *테스트* 로 연결 확인
| 거리 메트릭 | `cosine`(기본) / `l2` / `inner_product`
| 리랭커 | `none` / `llm` / `local` / `cross_encoder`
.3+| 청킹 | 전략 | `recursive`(기본) / `sentence` / `fixed`
| 청크 크기 | 조각 하나의 최대 글자 수(기본 1000)
| 오버랩 | 이웃 조각 겹침(기본 150, 크기보다 작아야 함)
|===

NOTE: 우측 *도움말* 패널에서 각 옵션·옵션값의 의미를 확인할 수 있습니다.

== OpenAI 호환 입력 흐름

. *서버 URL* 입력 → *테스트*(서버 `/health` 호출, 성공 시 모델·차원 자동 처리)
. *모델 불러오기* → 서버 `/v1/models` 목록에서 선택(직접 입력 불가 — 오타 방지)
. *차원 감지* → 서버에 샘플 임베딩을 보내 실제 차원을 자동 설정

자세한 내용: xref:kb/embedding-chunking.adoc[임베딩·청킹·거리 메트릭], xref:kb/reranking.adoc[리랭킹].
