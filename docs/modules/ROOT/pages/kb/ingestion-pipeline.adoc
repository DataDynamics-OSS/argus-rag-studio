= 인제스천 보강 파이프라인

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

파싱·청킹 사이에 끼워 넣는 *보강 단계(transform)* 를 지식베이스별로 구성합니다. 문서 속
이미지를 검색 가능하게 만들거나(이미지 캡션), 개인정보를 가리는(PII 마스킹) 등 원문을
넘어서는 가공이 필요할 때 사용합니다. 화면: 지식베이스 상세 > *인제스천 파이프라인*.

== 파이프라인 구조

다룰 내용:

* post_parse(파싱 직후, 문서 단위) / post_chunk(청킹 직후, 청크 단위) 두 훅의 차이와
  각 단계가 어느 훅에 속하는지.
* 단계 추가·순서 변경·설정 편집 UI 사용법, 저장 시 검증.
* 변경 후 기존 문서에 반영하려면 재인덱싱이 필요하다는 점(xref:kb/reindex.adoc[재인덱싱]).

== 이미지 캡션 (image_captions)

다룰 내용:

* 무엇을 하는가 — 문서 속 차트/표/다이어그램 등을 VLM 으로 인식해 본문에 요약을 주입,
  검색 결과에 이미지 근거 표시.
* 대상 이미지 유형 선택(chart/table/diagram/screenshot/formula), 문서당 상한, 상세 포함
  여부 등 옵션별 의미와 비용(이미지당 VLM 1회) 트레이드오프.
* VLM 지정 — 전역 설정(기본) vs 이 지식베이스만 다른 서비스(비교 테스트용).
* 지원 포맷별 커버리지(PDF·PPTX·DOCX·HTML·HWPX, HWP 바이너리 제한).

== PII 마스킹

다룰 내용:

* 색인 전에 개인정보를 마스킹하는 단계 구성 — 규칙(정규식)과 사용자 정의 함수의 선택.
* 규칙 관리 화면과의 관계(xref:ops/pii-rules.adoc[PII 규칙]).
* 마스킹은 색인본에만 적용되고 원본은 그대로라는 점(다운로드·미리보기 주의).

== 기타 단계

다룰 내용:

* 제공되는 나머지 transform 목록과 한 줄 용도(화면의 단계 추가 목록 기준으로 정리).

== 검증 방법

다룰 내용:

* 파싱 미리보기·소량 문서로 파이프라인을 확인한 뒤 전체 재인덱싱하는 권장 절차.
