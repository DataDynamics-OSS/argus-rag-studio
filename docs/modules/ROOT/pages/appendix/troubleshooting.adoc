= 문제 해결

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다. 운영 중 실제로 겪은
문제를 "증상 → 원인 → 조치" 항목으로 누적합니다.
====

증상에서 출발해 원인 화면으로 안내하는 *역방향 색인* 입니다.

== 문서를 넣었는데 검색이 안 됨

다룰 내용:

* 진단 순서 — 잡 모니터링(실패/대기) → 워커 상태 → 임베딩 서버 연결 → 문서 상태.

== 검색 품질이 낮음

다룰 내용:

* 점검 순서 — 청킹 설정 → 임베딩 모델/차원 → 하이브리드 모드·리랭킹 → 평가로 정량화.

== 서비스가 연결되지 않음

다룰 내용:

* 서비스 상태 배지 → 에이전트 하트비트 → 헬스체크 → 로그 순서의 점검 절차.

== 라우팅이 엉뚱한 곳으로 배분함

다룰 내용:

* 라우팅 테스트로 trace 확인 → 규칙 순서/임계 점검 → 검토 대기·규칙 제안 활용.

== 자주 나오는 오류 메시지

다룰 내용:

* 대표 오류 문구별(중복 문서 409, 차원 불일치, 라우팅 실패 422 등) 의미와 조치 표.
