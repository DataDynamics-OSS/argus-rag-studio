= API 레퍼런스

REST API 는 `/api/v1` 아래에 마운트됩니다. 대화형 스펙은 백엔드 기동 후
`http://localhost:4700/docs`(Swagger UI) / `/redoc` 에서 확인하세요.

== 인증

`POST /api/v1/auth/login` → JWT. 이후 요청은 `Authorization: Bearer <token>`.

== 라우터 그룹

[cols="1,3"]
|===
| `/api/v1/auth` | 로그인, 토큰, 비밀번호 변경
| `/api/v1/usermgr` | 사용자 CRUD·역할
| `/api/v1/permissions` | 메뉴/기능 권한
| `/api/v1/collections` | 지식베이스(컬렉션) CRUD, 문서 업로드, 인제스천/재인덱싱
| `/api/v1/embedding` | 임베딩/리랭커 서버 헬스·모델 목록·차원 probe, 파싱 전략 (`/health`, `/server-models`, `/probe`, `/local-models`, `/rerank-models`, `/local-rerank-models`, `/parse-strategies`)
| `/api/v1/pipelines` | 검색·생성 파이프라인 정의·버전
| `/api/v1/eval` | 평가 데이터셋·Run
| `/api/v1/feedback` | 답변 👍/👎 수집, 골든셋 승격
| `/api/v1/observability` | 운영 트레이스·메트릭
| `/api/v1/settings` | 런타임 설정 조회·갱신
|===

검색·생성 핵심 동작은 파이프라인 실행 엔드포인트를 통하며, 각 응답은 검색 메타데이터
(distance_metric, 점수, 청크 출처)를 포함합니다 — xref:../rag/search.adoc[검색] 참조.
