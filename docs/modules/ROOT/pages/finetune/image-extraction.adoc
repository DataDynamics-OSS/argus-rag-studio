= 이미지 추출 및 분석

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

문서(또는 URL)에서 *이미지를 추출하고 VLM 으로 인식·분석* 해 보는 화면입니다. 인제스천의
이미지 캡션이 어떻게 동작할지 미리 확인하거나, 이미지 라벨링의 원천 데이터를 만들 때
씁니다. 화면: 파인 튜닝 > *이미지 추출 및 분석*.

== 추출

다룰 내용:

* 입력(파일 업로드/URL)과 지원 포맷, 작은 이미지 제외(drop_small) 옵션.
* 진행 스트리밍 표시와 배치 결과 화면.

== VLM 분석

다룰 내용:

* 추출된 이미지의 유형 분류(chart/table/…)·요약·OCR 결과 읽는 법.
* 사용하는 VLM(전역 설정)과 미설정 시 안내.

== 활용 흐름

다룰 내용:

* 인제스천 이미지 캡션(xref:kb/ingestion-pipeline.adoc[보강 파이프라인])의 사전 점검 용도.
* 분석 결과를 이미지 라벨링 폴더로 보내는 연계.
