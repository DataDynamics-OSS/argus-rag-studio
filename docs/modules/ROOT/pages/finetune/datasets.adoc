= 학습 데이터셋

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

라벨링 결과를 *학습 가능한 데이터셋으로 구성* 합니다. 화면: 파인 튜닝 > *학습 데이터셋*.

== 데이터셋 만들기

다룰 내용:

* 데이터셋 생성 폼(이름·과제(task)·기반 지식베이스·프롬프트 포맷) 필드별 의미.
* 예시(example) 추가 경로 — 라벨링 결과 가져오기 / 직접 추가.

== split 관리

다룰 내용:

* train/val/test 분할 개념과 비율 조정 — test 는 홀드아웃(내보내기 불가)이라는 규칙과
  그 이유(오염 방지).
* split 재분배 시 주의.

== 내보내기 (외부 트레이너 연계)

다룰 내용:

* JSONL 내보내기 형식(외부 트레이너 계약 포맷)과 split 별 내보내기 규칙.
* 내보낸 데이터로 외부 환경에서 학습하는 경우의 절차 개요.

== 다음 단계
