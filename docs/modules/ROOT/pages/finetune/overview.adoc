= 파인 튜닝 개요

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

기성 모델로 부족한 *도메인 특화 성능이 필요할 때*, 사내 데이터로 학습 데이터셋을 만들고
모델을 학습·배포하는 여정입니다. 8부의 문서들은 데이터 준비(라벨링) → 데이터셋 구성 →
학습 → 모델 등록·배포 순서입니다.

== 언제 파인 튜닝이 필요한가

다룰 내용:

* 파인 튜닝 전에 먼저 시도할 것들 — 청킹/임베딩 모델 교체, 리랭킹, 프롬프트(비용 대비
  효과 순서).
* 파인 튜닝이 유효한 신호 — 도메인 용어 검색 실패, 평가 지표 정체 등.
* 학습 대상(임베딩/리랭커/생성)별 기대 효과.

== 전체 흐름 지도

다룰 내용:

* 원천 데이터 → 라벨링(텍스트/이미지) → 학습 데이터셋(split) → 학습 작업 → 모델 등록 →
  서비스 배포 → 평가로 검증, 각 단계의 화면과 담당 역할.
* xref:finetune/glossary.adoc[용어 사전] 을 먼저 읽어야 하는 이유(라벨·split·홀드아웃 등).

== 준비물

다룰 내용:

* 필요한 서비스(VLM — 이미지 분석용, 학습 인프라)와 권한.
* 데이터 거버넌스 주의(PII 포함 데이터의 라벨링·학습 사용 정책).
