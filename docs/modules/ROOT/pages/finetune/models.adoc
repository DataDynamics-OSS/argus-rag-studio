= 학습 모델 등록·배포

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

학습 산출 모델을 *레지스트리에 등록하고 서비스로 배포* 해 실제 파이프라인에 반영하는
마지막 단계입니다. 화면: 파인 튜닝 > *모델* (+ 관리 > 모델 = 레지스트리).

== 파인 튜닝 모델 화면

다룰 내용:

* 학습 작업 산출물 목록과 상태, 산출 모델의 메타데이터(베이스·데이터셋·지표).
* 산출물을 모델 저장소(Model Repository)에 올리는 절차.

== 레지스트리 등록과 배포

다룰 내용:

* xref:infra/model-registry.adoc[모델 레지스트리] 에 항목으로 등록하는 방법(종류·차원 등
  파라미터 일치 주의 — 임베딩이면 기존 컬렉션 차원과의 호환).
* xref:infra/service-deploy.adoc[서비스 배포] 로 올리고 트래픽 전환하는 순서(기존 서비스와
  병행 배포 → 일부 지식베이스만 오버라이드로 비교 → 전역 전환).

== 효과 검증

다룰 내용:

* 교체 전후를 xref:eval/evaluation.adoc[평가] 로 비교하는 권장 절차(같은 골든셋, 파이프라인
  버전 분리).
* 롤백 방법(이전 서비스로 재연결).
