= 텍스트 라벨링

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

텍스트 학습 데이터(질의-문서 쌍, 분류 라벨 등)를 만드는 화면입니다. 화면: 파인 튜닝 >
*텍스트 라벨링*.

== 라벨링 대상과 작업 단위

다룰 내용:

* 어떤 원천에서 라벨링 대상을 가져오는가(지식베이스 문서/청크, 업로드).
* 라벨 유형별 작업 방식과 UI(선택·태깅·쌍 구성).

== 작업 흐름

다룰 내용:

* 라벨링 세션 시작 → 항목 처리 → 저장/건너뛰기 → 진행률 관리.
* 여러 사람이 나눠 작업할 때의 분배·품질 관리 방법.

== 결과물과 다음 단계

다룰 내용:

* 라벨링 결과가 xref:finetune/datasets.adoc[학습 데이터셋] 으로 이어지는 흐름.
