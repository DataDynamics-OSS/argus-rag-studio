= 학습 작업

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

데이터셋으로 *학습을 실행하고 진행을 추적* 합니다. 화면: 파인 튜닝 > *학습 작업*.

== 학습 작업 만들기

다룰 내용:

* 작업 생성 폼 — 데이터셋·베이스 모델·하이퍼파라미터(에폭·러닝레이트·배치) 필드별
  의미와 권장 시작값.
* 학습 인프라 요구사항(GPU 서버)과 실행 위치.

== 진행 추적과 결과

다룰 내용:

* 작업 상태·로그·지표(loss 등) 읽는 법, 실패 시 원인 확인.
* 중단/재시작 규칙.

== 결과 모델 평가

다룰 내용:

* 학습 결과를 어떻게 검증하는가 — val/test 지표 확인, 평가(7부)와의 연계 방법.
