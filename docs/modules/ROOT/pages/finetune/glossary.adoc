= 용어 사전

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

파인 튜닝 기능군에서 쓰는 *용어를 관리하는 화면* 과, 매뉴얼 독자를 위한 *개념 용어 정리*
를 함께 담습니다. 화면: 파인 튜닝 > *용어 사전*.

== 용어 사전 화면 사용법

다룰 내용:

* 용어 등록·수정·삭제와 검색 — 어떤 용어를 등록해 두면 좋은가(도메인 약어, 라벨 정의).
* 용어가 다른 화면(라벨링 등)에서 어떻게 참조되는지.

== 개념 용어 정리 (독자용)

다룰 내용(표로 정리):

* 라벨/어노테이션, bbox, 데이터셋 split(train/val/test), 홀드아웃, 에폭/러닝레이트 등
  학습 작업 화면에 등장하는 용어의 한 줄 정의.
