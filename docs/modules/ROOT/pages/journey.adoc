= 사용 여정 한눈에 보기

이 매뉴얼은 *RAG Studio 를 처음 도입해 운영 궤도에 올리기까지의 순서* 그대로 구성되어
있습니다. 목차를 위에서 아래로 따라가면 됩니다. 이미 구축이 끝난 환경의 일반 사용자는
4부(문서 넣기)와 6부(검색·질의)부터 보면 됩니다.

[cols="1,3,2", options="header"]
|===
| 단계 | 무엇을 하는가 | 주 대상

| 1부 시작하기
| 15분 퀵스타트 — 최소 구성으로 지식베이스 하나를 만들고 질의까지 경험
| 모든 사용자

| 2부 설치·구축
| 시스템 요구사항 확인, 인프라(DB·오브젝트 스토리지)와 애플리케이션 배포
| 시스템 관리자

| 3부 모델·서비스 준비
| 원격 서버(에이전트) 등록 → 모델 반입(레지스트리) → 임베딩/리랭커/VLM 등
  추론 서비스 배포 → 전역 설정에 연결
| 시스템 관리자

| 4부 지식베이스 구축
| 컬렉션 생성(임베딩·청킹 설계) → 문서 인제스천 → 보강 파이프라인(이미지
  캡션·PII) → 재인덱싱 운영
| 지식 관리자

| 5부 문서 자동 배분
| 문서를 어느 지식베이스로 넣을지 규칙(정책)으로 자동화 — 소스 등록, 폴더
  일괄 반입, 주기 스캔, 저신뢰 결정 검토
| 지식 관리자

| 6부 검색·생성 활용
| Playground 로 검색 품질 확인, Chat 으로 질의, 파이프라인으로 설정 실험
| 최종 사용자·지식 관리자

| 7부 평가·품질 개선
| 골든셋 평가로 지표 측정, 사용자 피드백 수집·승격, 트레이스로 병목 분석
| 지식 관리자

| 8부 파인 튜닝
| 도메인 특화가 필요할 때 — 라벨링으로 학습 데이터를 만들고 학습·모델 등록·
  배포까지
| ML 담당자

| 9부 운영 관리
| 사용자·권한·인증, API 키, PII 규칙, 스토리지, 잡 모니터링 등 상시 운영
| 시스템 관리자
|===

== 역할별 추천 경로

* *시스템 관리자(최초 구축)*: 2부 → 3부 → 9부(사용자·권한) → 4부의 지식베이스 생성까지
  동행 후 지식 관리자에게 인계.
* *지식 관리자*: 4부 → 5부 → 6부 → 7부 순서로. 문서가 여러 출처에서 계속 들어오는
  환경이라면 5부(자동 배분)가 운영 부담을 크게 줄입니다.
* *최종 사용자*: xref:rag/playground.adoc[Playground] 와 xref:rag/chat.adoc[Chat] 두 문서면
  충분합니다.
* *ML 담당자*: 8부. 학습 결과 모델을 서비스로 올리는 흐름은 3부와 연결됩니다.
