= 메뉴 및 기능 권한

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

역할(사용자 그룹)별로 *어떤 메뉴를 보이게 하고 어떤 기능을 허용할지* 를 관리합니다.
화면: 관리 > *메뉴 및 기능 권한*.

== 권한 모델 이해

다룰 내용:

* 메뉴 권한(화면 노출)과 기능 권한(생성/수정/삭제/실행 등 세부 동작)의 2단 구조.
* 관리자(admin)·슈퍼유저·일반 사용자의 기본 권한 차이.

== 권한 구성 방법

다룰 내용:

* 권한 매트릭스 화면 사용법 — 메뉴별·기능별 토글.
* 대표 역할 프리셋 예시(최종 사용자 = Playground/Chat 만, 지식 관리자 = 지식베이스·라우팅
  포함, 시스템 관리자 = 전체).

== 검증과 주의

다룰 내용:

* 권한 변경이 반영되는 시점과 확인 방법(해당 계정으로 재로그인).
* 화면을 숨겨도 API 접근이 통제되는 범위(백엔드 권한과의 관계).
