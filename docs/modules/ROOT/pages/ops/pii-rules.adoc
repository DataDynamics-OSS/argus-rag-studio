= PII 규칙

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

색인 과정에서 개인정보를 가리는 *마스킹 규칙과 사용자 정의 함수* 를 관리합니다. 화면:
관리 > *PII Rule*.

== 규칙(정규식) 관리

다룰 내용:

* 기본 제공 규칙(주민번호·전화번호·이메일 등)과 커스텀 규칙 추가 방법.
* 마스킹 방식(치환 문자열)과 테스트 입력으로 확인하는 절차.

== 사용자 정의 함수

다룰 내용:

* Python 함수로 복잡한 마스킹을 구현하는 방법 — 작성 계약과 샌드박스 제약(import 금지,
  시간/메모리 제한).
* 함수 테스트·버전 관리.

== 인제스천 연계

다룰 내용:

* 규칙/함수가 지식베이스의 보강 파이프라인 단계로 연결되는 흐름
  (xref:kb/ingestion-pipeline.adoc[인제스천 보강 파이프라인]).
* 원본은 보존되고 색인본만 마스킹된다는 원칙과 운영상 주의(미리보기·다운로드 경로).
