= 잡 모니터링

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

인제스천(파싱→청킹→임베딩→색인) *잡의 진행과 실패를 추적* 합니다. 문서를 넣었는데 검색이
안 될 때 가장 먼저 볼 화면입니다. 화면: *잡 모니터링*.

== 잡 목록 읽는 법

다룰 내용:

* 상태(queued/running/succeeded/failed)와 단계별 진행률(parse/enrich/chunk/embed/index)의
  의미.
* 필터·검색으로 특정 문서/지식베이스의 잡 찾기.

== 실패 잡 처리

다룰 내용:

* 실패 사유 읽는 법(대표 원인: 파싱 실패, 임베딩 서버 연결, 차원 불일치)과 각각의 조치.
* 재처리 방법(문서 재인덱싱)과 재처리의 멱등성(기존 청크 교체).

== 워커 이해

다룰 내용:

* 잡을 처리하는 워커의 존재와 상태 확인 위치(서비스 관리 탭).
* 잡이 queued 에서 멈춰 있으면 워커부터 확인하라는 진단 순서.
