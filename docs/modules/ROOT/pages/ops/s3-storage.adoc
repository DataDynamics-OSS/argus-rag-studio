= S3 스토리지 브라우저

[NOTE]
====
*구조 초안* — 목차와 각 절에 담을 내용의 방향만 잡아둔 문서입니다.
====

RAG Studio 가 원본 문서·모델 팩 등을 보관하는 *내부 오브젝트 스토리지(MinIO/S3)를 열람*
하는 화면입니다. 장애 분석이나 데이터 확인이 필요할 때 씁니다. 화면: 관리 > *S3 스토리지*.

== 화면 사용법

다룰 내용:

* 버킷·프리픽스 탐색, 객체 다운로드, 검색.
* 주요 버킷의 용도 지도 — 원본 문서(컬렉션별 경로 규칙), 모델 팩(argus-models) 등.

== 운영 시나리오

다룰 내용:

* 문서 원본 확인(색인 결과가 이상할 때 원본 대조).
* 스토리지 용량 관리 관점 — 무엇이 용량을 차지하고 정리 가능한 것은 무엇인가.

== 주의

다룰 내용:

* 화면에서의 삭제·수정이 시스템 정합성에 미치는 영향(문서 레코드와 원본의 불일치) —
  임의 조작 금지 원칙.
