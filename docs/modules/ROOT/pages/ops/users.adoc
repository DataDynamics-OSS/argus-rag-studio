= 사용자·권한

== 사용자 관리

관리자는 사용자 관리 화면에서 사용자 생성·수정·역할 부여를 수행합니다. 역할은
`argus-admin` / `argus-superuser` / `argus-user` 입니다.

== 권한(메뉴/기능)

권한은 open-by-default — 제한 항목만 저장합니다. 권한 관리 화면에서 역할별 메뉴·기능 접근을 통제합니다.

* *메뉴* — 사이드바 항목(지식베이스·Playground·Chat·파이프라인·평가·운영·피드백·관리).
* *기능* — 메뉴 내부 동작(지식베이스 생성/삭제, 문서 업로드/재처리/삭제 등).

행이 없는 권한 키는 전 역할 허용이며, 제한하려면 권한 레지스트리에 항목을 추가합니다.
