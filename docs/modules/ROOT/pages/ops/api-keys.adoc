= API 키 (외부 시스템 연동)

외부 시스템이 RAG Studio 의 검색·질의·챗 기능을 **프로그래밍 방식으로** 호출할 때 쓰는
장기 자격 증명입니다. 사용자 로그인(JWT) 없이도 서비스 계정처럼 동작합니다.

== 개념

* 키는 발급 시 평문(`argus_sk_…`)이 **1회만** 노출되고, 서버에는 SHA-256 해시만 저장됩니다.
* 권한은 역할(`role_id` — `argus-admin` / `argus-superuser` / `argus-user`)로 부여합니다.
  외부 연동은 보통 `argus-user` 로 충분합니다(검색·질의·챗 호출).
* 관리(발급·폐기·활성화)는 **admin 전용**입니다.

== 발급

대시보드 → `관리` → `API 키` → `API 키 발급`. 이름·역할·만료(선택)를 지정하면 평문 키가
한 번 표시됩니다. 그 자리에서 복사해 안전하게 보관하세요(이후 복원 불가).

REST 로도 발급할 수 있습니다(admin JWT 필요):

[source,bash]
----
curl -X POST https://<host>/api/v1/api-keys \
  -H "Authorization: Bearer <admin-jwt>" \
  -H "Content-Type: application/json" \
  -d '{"name": "사내 챗봇 연동", "role": "argus-user", "expires_in_days": 90}'
# → 응답의 "api_key" 필드가 평문 키(1회 노출)
----

== 사용

발급된 키를 요청 헤더에 넣어 호출합니다. 두 가지 방식 모두 지원합니다.

* 전용 헤더: `X-API-Key: argus_sk_…`
* 표준 헤더: `Authorization: Bearer argus_sk_…` (키 접두사 `argus_sk_` 로 JWT 와 구분)

[source,bash]
----
# 인용 포함 답변 생성
curl -X POST https://<host>/api/v1/collections/<id>/query \
  -H "X-API-Key: argus_sk_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "질문 내용"}'

# 하이브리드 검색
curl -X POST https://<host>/api/v1/collections/<id>/search \
  -H "Authorization: Bearer argus_sk_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "질문 내용", "top_k": 5}'
----

== 폐기·관리

* `활성` 토글로 일시 비활성화(연동 즉시 차단), `폐기`로 영구 삭제.
* 만료가 지난 키는 자동으로 인증에 실패합니다.
* 마지막 사용 시각이 기록되어 미사용 키를 식별할 수 있습니다.

[NOTE]
====
키 노출 사고 시 해당 키를 폐기하고 새 키를 발급하세요. 키는 해시로만 저장되므로
서버에서 평문을 다시 확인할 수 없습니다.
====
