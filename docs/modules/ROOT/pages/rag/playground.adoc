= Playground

Playground 는 검색·리랭크·생성 파이프라인을 한 화면에서 확인·튜닝하는 도구입니다.

== 사용

. 지식베이스 선택, 검색 방식(하이브리드/벡터/렉시컬), 리랭크 여부 선택.
. 질문 입력.
. *검색만* — 청크와 점수만 확인. / *답변 생성* — 인용 포함 답변 + 청크.

== 결과

* *답변* — 본문에 `[n]` 인용 마커, 하단에 출처 청크(문서명·텍스트) 매핑.
* *검색된 청크* — 문서명·seq·score. 카드 헤더에 *검색 방식* 과 *거리 메트릭* 배지 표시(렉시컬 모드는 거리 미표시).
* *피드백* — 답변 하단 👍/👎 버튼. 👎 는 코멘트·수정답변을 받아 평가 골든셋 보강에 활용(xref:../eval/feedback.adoc[피드백 루프]).

== 트레이스 연결

질의 응답에는 `trace_id` 가 포함되어, 피드백이 특정 답변에 귀속되고 운영 화면에서 추적됩니다.
