= Chat

Chat 은 지식베이스 기반 멀티턴 대화입니다. SSE 로 토큰을 스트리밍하고 출처를 함께 보여줍니다.

== 동작

. 지식베이스 선택, (선택) 리랭크 토글.
. 메시지 입력 → 마지막 사용자 메시지로 검색 → 답변을 토큰 단위로 스트리밍.
. SSE 이벤트: `hits`(검색 결과 + 모드·거리 메트릭) → `token`(스트림) → `citations`(출처) → `done`(`trace_id`).

== 답변

* 본문 + 출처 인용([n]).
* 검색 방식·거리 메트릭 배지.
* 답변 하단 👍/👎 피드백 위젯(`trace_id` 로 귀속).

대화 비우기로 컨텍스트를 초기화할 수 있습니다.
